# Dev Practice

A comprehensive collection of learning projects, coding challenges, and practical exercises for full-stack development.

##  Project Structure

###  Learning (`learning/`)
Collection of coding challenges and algorithm problems from various platforms.
- **codewars/** - Solutions to Codewars problems
- **js-quiz-practice/** - JavaScript quiz and practice exercises

###  Projects (`projects/`)
Full-featured applications built from scratch for practical learning.
- **Modern-Web-Todo/** - Modern TODO application with JavaScript, HTML, CSS
- **Text-Editing-And-Analysis-Tool/** - Text editor with analysis features

### Security (`security-practice/`)
Security-focused projects for learning web vulnerabilities and protection.
- **XSS-Stored/** - Stored XSS vulnerability examples and prevention techniques

### Automation (`automation/`)
Bots and automation scripts for various tasks.
- **tewitt-telegram-bot/** - Twitter to Telegram channel forwarding bot
